# 分享范围与脱敏

本包采用文件白名单，只选择视觉追踪、检测、视频GUI、模板定位及OC-SORT。新增SDK和示例没有导入 `mscly` 主包。

未包含：主窗口main_window、远程Host/client、账号登录、战斗、导航、休息、频道控制、推送、上传、配对凭据、API密钥、个人配置、代理配置、训练工具、视频、标注、实验成绩明细、私人Git记录、虚拟环境或缓存。

视觉核心保留现有代码，包括其相关注释与第三方公开来源。目录中的 `experimental` 是历史命名；运行入口选择的是当前生产追踪器。没有复制原项目pyproject，独立requirements仅列所需公开依赖。

V4模型移除训练参数、训练指标、结果、Git元数据和训练时间；清空附着的训练args与criterion，清理配置内本机绝对路径。重新保存后文件SHA256自然变化，不能用原模型文件哈希证明字节一致；使用张量逐项相等以及实际检测输出比较验证推理内容保留。

第三方许可证、公开文档URL和作者署名保留，不属于应删除的私人信息。扫描同时检查文本文件、ZIP成员路径、模型pickle元数据字符串与PNG元数据。扫描是明确规则和白名单审查，不承诺数学上不存在任意未知形式秘密。

分享包与原项目分开生成，未改生产算法、模型或本机设置。接口封装和示例属于本包新增代码，不自动加入原程序运行链。

分享副本的GUI仅修改版本标题和初始匹配度（旧独立GUI为0.35，分享副本为0.15）；核心追踪算法文件保持来源字节一致。

接收者应按第三方及模型自身许可处理后续分发。本包附带说明不是对整个私人项目的开源声明。

## 0. 三十秒速览

**这是什么**：一台 PC 上跑的「**双机视觉自动化**」工作台 —— 用视觉识别游戏画面 + 小地图，
做**寻路 / 战斗 / 采集**的自动决策；外加一条**数据集流水线**（采集 → 标注 → 数据集 → 训练 → 验证 → 迭代）。

**技术栈**：Python 3.10 + PyQt5 + ultralytics(YOLO) + PyAV + OpenCV。**不是** web 项目，没有构建步骤。

**怎么跑起来**：`pythonw -m gui.app`（工作台入口）。配置在 `config/`，按项目的参数在 `projects/<项目名>/project.yaml`。

**跑一遍自检（最重要的习惯）**：

```powershell

$env:PYTHONIOENCODING='utf-8'; $env:QT_QPA_PLATFORM='offscreen'
python -u -m tools.selftest_decision      # 单套
python -m tools.check_ui                  # UI 规范自检
python -m tools.gui_smoke                 # 界面冒烟（真构造所有卡片/面板）
```

## 2. 一帧数据怎么走（改任何东西前先建立这个心智模型）

```
采集(窗口/文件/推流)  ──►  gui/live_thread.py: LiveThread(LiveThread线程)
   ├─ YOLO 推理  ─────────► 玩家框 / 怪框（画面像素）
   ├─ 小地图整帧 ─────────► perception/minimap: 黄点 → 世界坐标
   │                          └─► apply_to_player() 写 ws.player.world_x/y  ★唯一来源
   ├─ 框面积闸（检测有效吗）─► 决定"这一拍要不要查小地图"
   └─ PlayerTracker.update(cands, world=…)  ─► 挑出"哪个框是我"
        └─► 写 ws.player（画面坐标 x/bottom）
                          │
                          ▼
             perception/pos_state.py: PositionStateMachine
                （吃 loc ⇒ 广播 here_sets / ladder_id / at_ladder_top / ground_y）
                          │
                          ▼
             decision/agent.py: tick(ws)  ─► 按键输出（走/跳/攻击/爬/下跳）
                          │
                          ▼
             gui/live_panel.py 绘制（框/线/信息栏 OSD）
```

**⚠ 三条最要紧的坐标事实**（改动前必背）：

1. **玩家世界坐标只有一个来源**：小地图黄点。**没有第二个**。
2. **怪的世界坐标 = 怪画面坐标 + 相机**，而 `相机 = 玩家世界x − 玩家画面x`
   （`gui/live_thread.py:525`；主画面与世界 **1:1**，无缩放）⇒
   **玩家画面框抖 Δ ⇒ 每只怪同量平移 Δ**。所以"玩家画面坐标可信度"决定一切。
   ⭐ **2026-09-29 起相机有"可信"那一份了**：`PlayerTracker.camera()`（只在"框与黄点
   对得上"的那一拍更新 ✓）经 `ws.player.cam_x/cam_y` 供 `screen_to_world` 与怪的集合
   解析器用 ⇒ 框抖不再同量平移 ✓；差多少看 `behavior.log` 的 `cam_resid` ✓。
3. **画面坐标（YOLO 框）不稳定**；`PlayerTracker` 在「**只有一个候选**」时**无条件接受**
   （`perception/tracker.py`），而画面里通常只有玩家一人 ⇒ 那层"用黄点核对"**几乎不生效**。
   ⭐ 2026-09-29 补：**单候选时靠"两个传感器对不对得上"来兜**（隐含相机 vs 上次采纳的
   可信相机 ✗ 差得太多就不采纳它 ✓），它看不见的那类（框抖）由第一道 `max_jump` 闸接住 ✓。

## 3. 铁律（这个项目的开发纪律）

1. **改行为 ⇒ 必须"反向验证"**：故意把新逻辑改坏，**用例必须当场红**。
   不红 ⇒ 说明钉子没咬住（用例在自欺），先补用例再收工。
2. **别顺着"用户的判断"查** —— 用户说"打开某开关就不打怪了"，真因是**小地图标定少一半**。
   先看**现场证据**：`behavior.log` 打点、`nvidia-smi` 进程树、`git diff`。
3. **收工三件**：18 套全绿 + `tools.check_ui` + `tools.gui_smoke`；静态（`python -m pyflakes`）零新告警；
   **无临时文件残留**（`.rev`/`.bak`/`_tmp_*`）。
4. **不留死数据**：删掉的功能要把它的状态/配置/打点一起删干净。
5. **加新弹窗 ⇒ 先去搜谁在调那个入口**（`grep '<入口名>' tools/selftest_*.py`）——
   否则老用例会**真的弹出模态框**，在 offscreen 下**进程直接崩**（`0xC0000005`），不是断言失败。
6. **数值键要"写默认值 + 在 `load_*` 里加读回+夹范围"两处齐** —— 只写默认值 = 用户存的值进不来
   （表现"改了没用"）。
7. **信号连接一律放 `build_params()` 末尾**（控件按顺序创建，靠前的位置拿不到后面的控件、
   而且**静默失效**）；**别新增同名方法覆盖已有的**（留意 `pyflakes` 的 `redefinition`）。

## 4. 按模块：先看什么 → 怎么做 → 怎么核验

### 4.1 小地图 / 定位 / 世界坐标 ⭐（**当前任务就在这块**）

**先看**
- `perception/minimap.py`：`PlayerDotTracker`(黄点检测+防抖) / `PlayerLocator.update`(出参 dict)
  / `apply_to_player`(写 WorldState) / `has_geometry` / `live_src` / `stream_panel`
- `core/mapdata.py`：`load`(地形) / `load_calib` / `calib_path` / `Terrain`
- `gui/live_thread.py`：`_mmap_panel_from_frame` / `_locate_mmap` / 框面积闸那一段
- `docs/寻路设计.md` 里搜「黄点」「标定」
- 出参里这几个键是**判据**：`ok / held / confirmed / world_x / world_y / segment_id / foothold_id`
  ⇒ **`ok=False` 时 `world_x` 一定为 `None`**；而且 `ok=True` 后还有两个 early return
  （`terrain is None` / `not has_geometry`）也会让 `world_x` 为 `None`。

**怎么做**
- 小地图来源两种：`live.yaml` 的 `mmap_src` = `stream`（独立推流）或 `live`（从实时帧按
  `mmap_crop` 裁）。**取标定一律 `mm.live_src()` 得到来源，再 `mapdata.load_calib(map_id, src)`**。
- 标定文件 `datasets/map/<map_id>.mapcalib.json` 里，**生效的必要条件是**
  `mode` + `scale` + （`view` 或 `offset`）—— 只做了一半（缺 `scale`/`offset`）时
  `has_geometry` 为假 ⇒ **世界坐标恒空**。
- ⭐ **滚动方向（`scroll`）**：`"x"|"y"|"xy"`（标定窗「几何」那一节里选 ✓）——
  **只在不是双轴时才写进文件**（老标定没有这个键 ⇒ 按双轴算 ✓ 一字不变 ✓）。
  它**不改换算**：单轴 ⇒ 实时匹配只在会动的那根轴搜（更快 ✓），另一根轴一个字不改（防漂 ✓）。
- ⭐ **crop（局部小地图）会随玩家滚动** ⇒ 标定里那个 `view` 只在标定那一刻成立：
  `PlayerLocator.update` 每拍先跑 `perception.minimap.CropViewTracker` 跟一遍显示区
  （跟住才改几何；没跟住退回标定那份 ✓）⇒ 出参多了
  `view / view_ok / view_score / view_trust / view_why`；界面那行会报
  「显示区 (x,y)（跟住 0.93）」或「⚠ 显示区没跟住」✓。
- ⚠ `stream_panel()` **阻塞最多 5 秒** ⇒ **绝不在 UI 线程调**。

**怎么核验**
- 单套：`python -u -m tools.selftest_minimap`（含位置状态机、到顶/到底判据）
- 行为侧：实时页看小地图那行的 `short`/`note`（会直接说"没标定 / 认不出黄点 / 没有地形数据 / 算到图外"）
- 数据侧：`datasets/map/<id>.mapcalib.json` 里 `stream` 段有没有 `scale`/`offset`/`score`

### 4.2 决策 / 寻路

**怎么核验**

**怎么做**

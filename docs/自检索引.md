## 4. 耦合备忘（**该去哪加钉子**，别放错套件）

| 要钉的东西 | 放哪 | 为什么 |
|---|---|---|
| `live_thread` 的**纯逻辑**（判定 / 录屏 / 鼠标折回） | `selftest_screen_state` | 那个进程能干净地 `import gui.live_thread` ✓ |
| `live_panel` 的界面 / 管路闸 | `selftest_live_panel` | 它要 Qt + 真信号链 ✓ |
| ⚠ 想钉 `live_thread` 却放进 `selftest_live_panel` | **别** | 那个进程 import 会撞 `ultralytics` 的 DLL（`WinError 1114`）⇒ 整条判 FAIL ✓ **踩过** ✓ |
| 跨模块的边界（唯一写者 / 分层） | `selftest_arch` | 它有写者名单，改结构要**同步登记 + 写清 why** ✓ |

已消除的耦合（2026-10-17 ✓）：
- `mouse_aim.aim_to` / `click_ratio` 各自抄一份"取标定 + 后台自动量" ⇒ 收成
  `_gain_or_why()` ✓（上一轮接 `roi` 时就因漏改一处而点歪 ✓）；
- 部署台框选与本地框选共用一个换算口径 `mouse_aim.roi_px()` ✓（两处调用共用 ✓）。
